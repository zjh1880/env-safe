# Code of conduct

English | [中文](./CODE_OF_CONDUCT.zh.md)

## Our pledge

This is a small, focused project about configuration hygiene. Everyone is welcome to use it, report bugs, and send patches — regardless of experience level, language, background, or identity.

## Expected behaviour

- Be direct about the code and generous with the person. Review the patch, not the author.
- Keep reports reproducible: a command, an input file, and what actually happened.
- Assume good faith when someone's English or Chinese is imperfect; this project is documented in both languages.
- Respect that maintainers work on this in their own time.

## Unacceptable behaviour

- Harassment, insults, or personal attacks in issues, pull requests, or reviews.
- Dismissing a report because the reporter is new, or because the bug looks small.
- Publishing someone else's `.env` contents, credentials, or other private data — including as an "example" in an issue.
- Sustained disruption: re-opening the same rejected proposal, flooding threads, or derailing reviews.

## Scope

This applies to issues, pull requests, discussions, and any other space where someone is representing the project.

## Enforcement

If something is going wrong, contact a maintainer privately (see `SECURITY.md` for the private reporting route). Maintainers may edit or delete comments, close threads, or block accounts. Reports are handled confidentially, and we will tell you what we did.
